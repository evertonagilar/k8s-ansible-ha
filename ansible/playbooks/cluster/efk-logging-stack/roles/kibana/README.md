# Instruções para instalar novo kibana

## Instalação do volume do Kibana

O arquivo **usr_share_kibana_data_template.tar** contém a pasta /usr/share/kibana/data padrão para inicializar o volume
do Kibana já com uma configuração básica. Em uma instalação nova, depois de provisionar o volume do kibana, é preciso copiar os dados
para o volume.
